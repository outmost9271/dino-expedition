# 中华恐龙考察队·便携版

本分支仅保存可下载后直接使用的便携版，不包含 Nginx 静态分块或工程源码。

## 使用方法

1. 下载并解压本分支，或下载 [`portable-html` 分支压缩包](https://github.com/outmost9271/dino-expedition/archive/refs/heads/portable-html.zip)。
2. 保持目录结构完整，直接双击 `index.html`。
3. 推荐使用新版 Microsoft Edge 或 Google Chrome。

脚本与样式已经写入 `index.html`，无需安装、无需启动服务器、无需联网。`audio/voice/` 保存游戏旁白，因此不要只复制 `index.html`。
